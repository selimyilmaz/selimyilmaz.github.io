## 🤖 6. Otomatik Sürüm Senkronizasyonu (GitHub Actions & CI/CD)

Bu depodaki tüm proje sürüm bilgileri ([assets/js/projects-data.js](assets/js/projects-data.js)), ilgili kaynak depoların (17 repository) GitHub Releases ve Tags API'leri taranarak **tamamen otomatik** olarak senkronize edilir:

- **Zamanlanmış Görev (Cron):** Her gün 03:00 UTC'de GitHub Actions (`.github/workflows/sync-versions.yml`) arka planda çalışarak yeni bir release veya tag yayınlanmışsa sürüm dökümünü günceller ve depoya otomatik commit gönderir.
- **Manuel Tetikleme (Workflow Dispatch):** GitHub Actions sekmesinden tek tıkla *"Run workflow"* butonu ile istenildiği an çalıştırılabilir.
- **Yerel Çalıştırma (CLI):** Geliştirme ortamında terminal üzerinden tek komutla çalıştırılabilir:
  ```bash
  npm run sync-versions
  # veya
  node .github/scripts/sync-versions.js
  ```
